# Studio Hélio – Landing Page

## Stack choisie

J’ai utilisé **TanStack Start (Vite + Bun + TypeScript)** avec **Tailwind CSS** et **Framer Motion**.

- **TanStack Start** : framework moderne, rapide, et minimaliste, parfait pour un projet court et propre.
- **Tailwind CSS** : gain de temps pour un design responsive et cohérent.
- **Framer Motion** : animations fluides et premium.
- **Swiper.js** : carrousels pour témoignages et logos.

## Décisions de design/structure

1. **Effet glassmorphism** : pour donner un rendu moderne et premium.
2. **Carrousels interactifs** : preuve sociale (“Ils nous ont fait confiance”) et ambiance visuelle (images pilates).
3. **FAQ interactive** : accordéon animé pour dynamiser la section et améliorer l’expérience utilisateur.

## Améliorations possibles (si +1 semaine)

- Ajouter un **blog/ressources** pour booster le SEO.
- Optimiser les images en **WebP + lazy loading** pour améliorer la performance.
- Renforcer l’**accessibilité** (contrastes, ARIA labels).

## Emprunts

- **Librairies** : Framer Motion, Swiper.js, react-countup.
- **Assets** : images libres de droits (Unsplash/Pexels) et quelques visuels générés par IA.
